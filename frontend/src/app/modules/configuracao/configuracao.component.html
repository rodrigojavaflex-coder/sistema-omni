Integração ERP de vistoria

Ao finalizar uma vistoria com irregularidade, o OMNI envia a capa ao ERP de forma assíncrona. Desative para não enfileirar nem permitir reenvio na tela Vistorias.

Deixe em branco para manter a chave já salva. Use o olho para ver a chave gravada.
Usada se a API do ERP não devolver texto de erro. Sem preenchimento, vale “Erro ao gravar Vistoria no OMNI”.
